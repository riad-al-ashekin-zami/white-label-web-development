# White Label Web development

PROMPT 1 — HOMEPAGE DESIGN & STRUCTURE

Build a premium, modern, conversion-focused homepage for a “White Label Web Development Company” that works with agencies, marketers, SEO companies, consultants, and freelancers.

This is NOT a generic web design agency website.

The positioning should clearly communicate:
“We are the invisible backend development partner for agencies.”

The entire homepage should feel:

premium

trustworthy

scalable

clean

structured

agency-focused

SaaS-inspired

enterprise-level

modern B2B

DO NOT make it look:

childish

startup gimmicky

overly colorful

crypto style

dark hacker style

template-looking

overloaded with animations

The design should feel similar to:
high-end SaaS + modern agency + operational excellence.

==================================================
BRAND POSITIONING

Main positioning:
“White Label Web Development Partner for Agencies”

Secondary messaging:

Scale your agency without hiring developers

SEO-first websites built for agencies

Your brand. Our execution.

Invisible backend web development team

Reliable white label fulfillment partner

==================================================
TARGET AUDIENCE

This homepage is specifically designed for:

SEO agencies

Marketing agencies

Freelancers

Designers

Local SEO consultants

Digital agencies

Branding agencies

Do NOT target regular small business owners directly.

==================================================
DESIGN STYLE

Design must be:

ultra clean

spacious

modern typography

premium spacing system

strong visual hierarchy

subtle gradients only

smooth sections

rounded corners

glassmorphism only lightly if needed

strong CTA visibility

excellent mobile responsiveness

Use:

white background primarily

soft neutral colors

premium blue / indigo / black accent palette

minimal color usage

professional enterprise vibe

Typography:

bold modern headings

readable body text

strong contrast

large hero typography

==================================================
HEADER
